# 聚合壳 Demos · 导读

给选型讨论做素材的四个对照 demo：

- 01 / 02 是**同一个壳的两种写法** —— 对照状态管理选型（setState vs MobX）
- 03 是**聚合架构的本质** —— 微缩规则引擎，回答"规则仓库为什么能直接对接"
- 04 是**统一数据层的设计** —— 统一收藏/历史在存储层是什么形状

| Demo | 演示什么 | 怎么跑 | 重点看什么 |
|---|---|---|---|
| [01_shell_vanilla](01_shell_vanilla/main.dart) | MD3 桌面壳最小形态（纯原生组件） | 需 Flutter（先当代码读） | NavigationRail 侧栏、模块挂载点、"我的"页统一时间线 |
| [02_shell_mobx](02_shell_mobx/main.dart) | 同一个壳的 MobX 写法（Kazumi 同款） | 需 mobx + build_runner（先当代码读） | StatefulWidget 消失、Store / Observer / @action |
| [03_mini_rule_engine](03_mini_rule_engine/main.dart) | ~130 行微缩规则引擎 | 装 Dart 后 `dart run main.dart`（零依赖） | 规则=数据、引擎=解释器；列表→详情两级规则链 |
| [04_unified_library](04_unified_library/main.dart) | 统一收藏/历史库 schema（drift 风格） | 需 drift + codegen（先当代码读） | 公共列 + payload JSON 的取舍、复合主键 |

## 阅读顺序建议

1. **先读 03**（不依赖 Flutter，130 行）：它解释了整个项目最重要的架构认知——
   「换一个网站 = 换一份规则；引擎一行不用改」。看完你就明白为什么
   书源/漫画源/番剧规则仓库可以直接拿来用，而四套引擎必须由我们养着。
2. **对照读 01 和 02**：界面几乎一样，只看"状态住在哪里、UI 怎么响应"的区别。
   读完你就知道"状态管理选型"到底在选什么。
3. **最后读 04**：看"统一时间线"在数据层是一个什么形状的表。

## 讨论题（读完欢迎回来聊）

1. 01 的 setState 和 02 的 MobX，哪种手感更对你胃口？
2. 03 演示了"换源=换规则"——你觉得壳里需要一个"源管理"页吗（导入/启停/更新规则）？
3. 04 的"公共列 + payload JSON"够用吗？还是想现在就每类型一张表？

## 备注

- 所有 demo 刻意**单文件 + 中文注释**，为的是"读"而不是"跑"。
  本机目前没有 Flutter/Dart 环境，想跑的时候再搭，不着急。
- 01/02 的布局刻意照搬两家的现成模式：桌面侧栏 = Kazumi / Venera-Next 的做法，
  以后搬模块时 UI 骨架可以无缝对接。

## 追加：入口页版式提案（2026-11-17）

`entry_variants.html` —— **四版入口页的可交互 HTML mock**，单文件、无外部依赖，
双击即可打开（也可以 `python -m http.server` 起来看）。

- 四版：A 展厅（2×2 等权卡片）/ B 书架（横向长卡 + 模块内左侧导航）/
  C 拼贴（非对称色块）/ D 分栏（左四入口 + 右侧大预览）。
- 每版都实现了同一条动线：**四个入口 → 点进去 → 另外三个消失，只剩这一层 →
  左上返回**；模块内页带自己的标签页、FAB、音乐模块的底部播放条。
- 页面上方的「设置放哪」可切换三种方案：全局一个 / 分模块 / 两层都有，
  用来判断设置入口最后落在哪里。
- 主题色可切换三种 MD3 种子色（紫罗兰 / 苔绿 / 赭石），看同一套色角色是否撑得住。

**当前选择（2026-11-17）**：**C · 拼贴 + 全局一个设置**。
- 主界面是四块不等权色块：番剧全宽、漫画/小说并排、音乐全宽；进入后只剩该模块。
- 设置只有一个齿轮，抽屉内先按「外观 / 存储」折叠分组，再按
  番剧 / 漫画 / 小说 / 音乐 四个可折叠分组——总入口，但各自的设置分得清。
- 手机（≤560px 窗口宽）单独适配：番剧全宽 → 漫画/小说两列 → 音乐全宽，
  四个入口仍在同一屏内，已按 390×760 实测无裁切、无横向溢出。
  页面右上角可切「桌面 / 手机 390」直接看。

**注意**：这一版按"四入口 → 下一层"的新描述做，和 01/02 的 NavigationRail
五目的地旧壳不同。选定版式后，`docs/architecture.md` §1 的壳层描述与
`docs/directory-layout.md` 的 shell 文件清单需要同步改；**统一书架 / "我的" 在
四入口结构里放到哪里，是尚未拍板的问题**（首页下方"最近"条 / 顶栏入口 /
各模块收藏页，三选一或组合）。
