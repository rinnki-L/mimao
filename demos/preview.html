统一收藏/历史 = 四种媒体一张表（SQLite / drift，Demo 04）。公共字段做成列，各类型自己的进度塞进 payload JSON —— 起步不过度设计，将来要"按漫画页码筛选"时再升格成真列。最下面一行展示了它和 ① 里「我的」页的关系：那页吃的就是这张表。

表定义（drift 风格）

class MediaEntries extends Table { TextColumn get id => text()(); // 源内唯一键，如 "kazumi:1001" TextColumn get mediaType => textEnum<MediaType>(); // anime / comic / novel / music TextColumn get sourceName => text()(); // 来自哪个源/规则包 TextColumn get title => text()(); TextColumn get coverUrl => text().nullable()(); TextColumn get payload => text()(); // JSON：该类型自己的进度结构 DateTimeColumn get lastOpenedAt => dateTime()(); DateTimeColumn get createdAt => dateTime()(); // 复合主键：同一作品可以从多个源打开，靠它区分 primaryKey = { id, mediaType, sourceName } }
